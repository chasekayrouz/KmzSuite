Kmz2Viewer

MS2 scan browser and mass-difference hypotheses · version 0.12.1 · updated 2026-10-17

Open and browse

Use Open mzML (Command-O), Finder Open With or file drops. Multiple files are retained in an in-memory MS2 library; MS1 peak arrays are skipped. Clear files clears the library. The scan table shows source identity, retention time and available precursor/charge/energy metadata; missing values remain missing. Sort by a column and open a selected row to inspect that source scan. Clear and Cancel loading safely invalidate late results.

Open from KmzViewer

KmzViewer’s Open Kmz2Viewer for MS/MS dropdown opens a new session with selected current files or a blank library. Right-clicking an MS1 m/z label and choosing Open MS/MS in Kmz2Viewer opens that source file with only the precursor filter initialized to the full-precision mass at ±20 ppm. RT and fragment fields remain blank; all retention times and polarities are eligible. Existing Kmz2Viewer sessions keep their files and settings. No matching precursors means an empty result table; Clear filters shows every MS2 scan in the file.

Filter scans

Blank fields impose no restriction. Precursor m/z and fragment m/z use inclusive ppm or Da half-widths (20 ppm by default). Fragment ≥ % base peak requires a positive fragment-window signal and, when set, its height relative to the scan’s base peak. RT min/max are inclusive minutes. All active filters combine with AND. Clear filters restores the entire library. There is no collision-energy filter.

Inspect a spectrum

The dock displays the native profile/centroid spectrum, precursor mark, selected peak labels and metadata. Pan/zoom the plot; Full m/z range or F restores its full m/z and intensity bounds. F works while the spectrum area or scan table has focus, including a detached spectrum dock; typing in filter fields and dialogs remains normal. Previous/Next and Left/Right navigate matching rows in current table order, preserving the m/z window. Labels and formula connectors are recalculated for the visible range. The shared light theme keeps control states visible. Peak labels use measured pixel height for Y headroom and inward anchors at m/z edges; resizing and zooming recalculate the minimum space required.

Conditional formulas

The ten major peaks plus the precursor form positive, unique mass-difference pairs. A missing observed precursor can be a virtual anchor, not a measured peak. A known precursor charge above one suppresses precursor-related formula assignments because Δm/z is not an unambiguous neutral loss; other pairs remain available.

Show neutral losses toggles connectors. Formula settings control ppm tolerance (50 by default), maximum C/H/N/O/S counts and DBE bounds. DBE minimum is inclusive; maximum is exclusive (default 0–15 retains 0–14). Candidates use the preserved element/DBE rules and error ranking. Connector/tooltips expose candidate details. These are predicted formulas for mass differences, not identified fragments or confirmed structures.

Runtime and limitations

Loading is asynchronous with progress/cancellation. Document requests queue/deduplicate; close/quit waits for safe cleanup. Filtering and formula lookup remain synchronous. No smoothing, centroiding, library search, compound identification, persistent session or shared launcher state is introduced.

Help includes this manual and dependency notices. Launch dist/Kmz2Viewer.app independently, or .venv/bin/python -m kmz2viewer [run.mzML] during development. Add --precursor-mz 300.123456 before the file paths to initialize the same precursor-only ±20 ppm search.

Input compatibility

Version 0.3.0 uses the current KmzSuite conversion metadata. Both viewers reject obsolete suite outputs with: Legacy input received. Please reconvert using the current KmzConvert. Reconvert the original acquisition; renaming the mzML file or editing its header is not a migration. Ordinary third-party mzML remains supported.
