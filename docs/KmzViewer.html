KmzViewer

Chromatograms and native MS1/DAD spectra · version 0.12.0 · updated 2026-11-13

Open and manage runs

Use File → Open mzML (Command-O), Finder Open With, or drop one or more local .mzML files. Each run shows its MS1 TIC. The vendor TIC chromatogram is separate and is not the plotted scan list. Missing scan TIC values are computed from native intensities. Unknown scan-time units are rejected; seconds are converted to minutes.

Check traces to show/hide them. Shift-click selects a range; Command-click (Ctrl-click on other platforms) selects separate rows. Right-click the selection to Remove selected chromatograms, Extract EIC…, Show only selected (check the selected traces and uncheck all others), Hide selected, or Change selected color…. Selecting a parent file applies these actions to all its chromatograms; selecting it together with its children never duplicates work. Removing traces leaves their source files and MS1 spectrum inclusion intact. The context menu can also restore a removed TIC. Close selected files in File or the context menu closes every source represented by selected file, chromatogram or group rows, once per file, including all of its chromatograms and both spectrum types. A selected type group therefore closes every file in that group. With no selection, the File command closes the active source. Closing releases each source’s array cache and readers together. There is no saved scientific session. Each app remembers its own last directory.

The viewers use a shared light theme with dark text, visible check indicators, green control selections and white plots. Source colors appear as bordered swatches beside readable navigator names.

Remove, show and hide chromatograms

Use Remove/Show/Hide… below the navigator’s Sort button, or in the Chromatogram menu. The searchable dialog lists every loaded trace, including hidden plots. Broad TIC/BPC/EIC/TWC/EWC checkboxes select whole types; expand a type for exact extraction groups, then expand a group to choose individual files. Polarity, ppm, mass/range and EWC reference bands remain distinct. Tooltips show full settings and source paths; repeated copies remain separate entries.

Filter by type, mass, wavelength or filename. Group checkboxes and Select matching apply only to search matches. Previously checked traces outside the search stay selected and are explicitly counted. Clear selection clears all selections. Nothing starts checked. Space toggles a focused checkbox; Enter in the search field never applies an action.

Show plots and Hide plots change only the checked chromatograms. The numbered Remove button removes those traces from this session, clearing their filter results and emphasis. Source files, acquired arrays and MS1/DAD spectrum inclusion remain intact; even removing every trace leaves its source open for extraction or Restore TIC.

MS1 and DAD each have separate Show spectra, Hide spectra and Toggle spectra actions. These change the navigator’s spectrum eyes independently of plot visibility. Each source file represented by the checked traces is affected once, even if several of its traces are checked. Show includes all eligible selected files; Hide excludes them; Toggle flips each file’s current state, including mixed selections. The tree displays plot and spectrum states, and the footer counts eligible source files. MS1 requires a finite scan retention time. DAD becomes available after wavelength extraction, matching the navigator; unavailable files are skipped and an action with no eligible targets is disabled.

Actions apply immediately and keep the dialog open. Search, remaining checked traces and expanded groups survive each action; states and target counts refresh. Close or Escape dismisses the dialog without undoing applied changes. Closing before any action changes nothing. The entry command is disabled during file work or when no chromatograms remain.

Group and order files

The navigator defaults to Group by file. Choose Group by chromatogram type to collect matching extractions across files: TIC, BPC polarity groups, individual EIC settings, TWC and individual EWC settings. EIC mass/list/range, ppm and polarity must match exactly; EWC signal bandwidth and reference settings must also match. Rounded display names never determine identity. Groups appear by family and extraction order, with files in their existing order within each group. The chromatogram stack and initial SVG trace list follow this grouping; MS1 and DAD spectra retain file order.

Group checkboxes and bulk actions apply to their member chromatograms. Repeated file eyes control the same source’s spectrum inclusion and stay synchronized across groups. Selection, visibility, colors, zoom and each mode’s collapsed groups survive switching. Files with every chromatogram removed remain available under Files without chromatograms. Grouped filenames omit the .mzML/.sp.mzML ending and elide in the middle; full original names and paths remain in tooltips. Grouping is held only for the current session.

In file grouping, drag a parent file name or a selected group of file names to a new position. The insertion line marks a boundary between whole files; children always travel with their parent, and selected files keep their relative order. Drag near the list edge to scroll. Sort files A–Z applies case-insensitive natural alphanumeric order (Run 2 before Run 10). This order controls sources within the navigator and chromatogram groups, MS1/DAD spectra and the initial SVG export list. Switch to file grouping for manual file dragging; Sort files A–Z works in either grouping. Checks, trace colors, selection, collapsed groups and plot zoom are retained. Ordering is held only for the current session.

Chromatogram colors

Each source file receives one default color from a 24-color palette selected for perceptual separation and contrast on white. Its TIC and new BPCs/EICs start with that color, including later extractions and a restored TIC. Change selected color… overrides only the selected chromatograms, leaving unselected traces and MS1 spectrum colors unchanged. Colors repeat after the palette is exhausted; filenames and trace labels remain useful for many files.

Right-click a source name or any of its chromatogram names and choose Choose source color… to open the color picker. This source-wide command updates every trace from that source (including previously overridden colors), its legend samples and the faint under-curve fills. The fills derive from the base color and remain unchanged when a line is emphasized. The MS1 spectra use the same source colors. Colors and emphasis are held only in memory: closing and reopening a source assigns a new default, and a new application session starts with normal defaults. These changes never modify mzML inputs or create sidecars.

Extract EIC

Chromatogram → Extract EIC (Command-E) accepts a mass (273.1559), a comma-separated list, or an inclusive range (250-300). The dialog prechecks the source files of selected navigator rows, once per file; with no selection it checks all files. You can change those checks before extracting. Choose ppm half-width and All/Positive/Negative polarity. A range ignores ppm. Merge multiple masses to sum separate windows; overlapping windows count their shared points in each window. All polarity includes unspecified scans. Extraction uses native intensities, without smoothing or centroiding.

Extract BPC

Choose Extract BPC… in the toolbar, Chromatogram menu or navigator context menu. Like EIC extraction, selected navigator rows precheck their source files; no selection prechecks all files. Choose All / Positive / Negative MS1 polarity. Each file gains one independent base peak chromatogram: the highest finite native ion intensity in each selected scan. Empty scans contribute zero. All includes unspecified polarity. Profile data use the measured profile points; no centroiding or smoothing is applied.

m/z filter

The m/z filter above the chromatograms has Start and Stop fields with Apply and Clear. Enter finite, nonnegative values with Start ≤ Stop; both endpoints are included, and equal bounds select an exact acquired m/z. Apply restricts the contributing ions in every loaded ion trace: TIC sums intensities in the range, BPC takes the maximum there, and EIC intersects each original window with the range. Merged EICs retain window order and overlap multiplicity. Empty intersections contribute zero. Existing polarity selections, scan rows and retention times are preserved.

The range applies in stacked and overlay layouts, including traces shown later and new files/extractions. Wavelength traces and the MS1/DAD spectrum docks retain their native data. The active range appears above the plots and in filtered trace titles. SVG previews snapshot filtered values and identify the range; an already-open preview retains its snapshot.

New ranges calculate off the GUI thread with progress and cancellation, reusing decoded spectra when available. Recent completed results are kept in a bounded cache; reapplying one avoids spectral calculations. Changing visibility, layout or zoom only renders the prepared results. The prior view remains while a different range is calculated. Failed/cancelled requests leave it intact. Newly added ion traces wait for filtering before they appear or become exportable; use Apply to retry or Clear to reset after cancellation. Clear immediately restores the exact original traces and rejects late results. Inputs, acquisition TIC metadata and original extracted arrays are never edited, and the filter is not saved between sessions.

A filtered TIC sums available native points, so it may differ from acquisition TIC metadata even with a broad range. For Sparse Profile inputs, filtered TIC/BPC/EIC use retained measurements only; Clear restores the acquisition TIC. First use can require a full spectral pass, and files exceeding the native array-cache budget may need decoding again for new ranges. Use Full Profile inputs when full-fidelity sums are required.

DAD wavelength chromatograms and spectra

Open a converted mzML containing DAD spectra. No wavelength trace is shown automatically, and the DAD spectrum dock starts hidden. Use Wavelength → Extract TWC… / Extract EWC…, the Chromatogram menu, or the navigator context menu. Source files are preselected from the navigator just like EIC extraction. Files without usable DAD data are identified only when wavelength extraction is requested; other selected files can still be extracted.

TWC sums signed absorbance over all acquired wavelengths per scan. EWC averages the acquired samples within wavelength ± half the full bandwidth, optionally subtracting the mean of a separate reference wavelength/bandwidth. For example, 254 nm with a 4 nm bandwidth includes 252–256 nm. Comma-separated wavelengths create separate EWCs. Zero bandwidth requires an exact acquired wavelength. A band extending outside the acquired range or containing no acquired sample is rejected. No interpolation, smoothing or baseline correction occurs, and negative values remain visible.

Wavelength traces share selection, visibility, source/trace colors, ordering, emphasis, linked retention-time zoom, Full view, Walk and SVG export with ion traces. Their own acquired times drive navigation. Match Y groups counts and mAU separately. Adding a wavelength trace opens the movable, detachable DAD Spectra dock and reveals a second spectrum-eye column. Its eyes control DAD inclusion independently of MS1 and chromatogram visibility. Removing traces retains spectrum inclusion; closing their source removes both spectrum types.

Both spectrum sets follow the selected native retention time, using each detector’s nearest acquired scan and displaying actual times. DAD selections retain the current MS polarity, initializing from the nearest source MS scan when necessary; DAD has no polarity. Out-of-range runs show empty labeled panes. There is no temporal interpolation or detector-delay alignment. The DAD dock supports stacked/overlay comparisons, Match Y, linked wavelength zoom/pan, peak labels, native hover values and F full view, including while detached. Its Y range automatically follows the visible wavelength window, just as TWC/EWC Y follows the visible time window with Autoscale Y enabled. Linked panes and the right absorbance axis update together. Bounds include rendered line intersections at window edges, so zooming between acquired points still fits the visible line; these intersections never become measurements. Source colors apply to both spectrum types.

File → Export MS1 spectra… / Export DAD spectra…, or each dock’s Export… button, opens a live SVG preview of the displayed scans. Selection, ordering, colors, dimensions, fonts, shading, offsets, ranges, grids and stacked/overlay output are adjustable. The initial X range matches the dock. Centroid sticks and sparse MS1 zero-baseline geometry are retained. Export uses a snapshot in native counts or mAU, so subsequent navigation does not change an open preview. Viewer percent scaling is not applied to SVG previews; their native-unit axes and independent layout controls remain explicit.

Navigate traces and spectra

Choose stacked panes or Overlay. Stacked retention-time axes remain linked, with time ticks on every chromatogram and reduced pane margins and gaps. Pan and Zoom box select mouse behavior. Full view (Command-F or Command-0) restores the time and Y bounds, including after manual Y zoom. Press F while working in the chromatogram area to restore its full view, or while working in spectra to restore their full m/z and counts view. F applies to all linked panes in that area and also works in a detached spectrum dock. From the Data Navigator, F resets chromatograms. It does not change layout, inclusion, inspection position, or Autoscale/Match Y choices. Autoscale Y is on by default and follows the visible time window. Match Y axes is off by default. In stacked mode it shares either the visible automatic scale or a manual scale across panes, only within the same units. In Overlay, turning Match Y on shows shared absolute counts and, for wavelength traces, a separate absorbance (mAU) axis on the right. Turning it off scales each trace’s highest positive peak in the visible window to 100% on a shared relative-intensity axis. Each trace rescales independently during zoom and pan, even when manual Y bounds are retained with Autoscale Y off. Negative values keep their sign; a negative-only window uses its most negative point as −100%. Zero-only and empty traces remain zero or empty. This is display scaling only: source arrays, hover values, extraction, and scan selection remain native.

In Overlay mode, single-click the actual chromatogram stroke or its legend mini-line to toggle a darker line at twice the normal width. Multiple traces can stay emphasized independently. Legend mini-lines toggle emphasis only: they never hide traces or change navigator checks. Clicking empty plot space, axes or legend text does not emphasize a line. Emphasis waits for the system double-click interval so double-clicks remain scan-inspection gestures. Vertical stack mode has no emphasis or per-pane mini-line legends; source and TIC/BPC/EIC labels sit inside the upper-left plot boundary without reserving a title row or changing data bounds. Long labels elide in the middle with the full title available as a tooltip; labels hide when a pane is too short to fit them legibly. Overlay emphasis is retained in memory when switching modes, but vertical panes always render normal strokes.

Compare MS1 spectra

MS1 Spectra opens to the right of the chromatograms. The two plot areas start with equal widths, including when entering fullscreen or maximizing. Drag the dock divider to adjust them; View can hide the Data Navigator or the spectrum dock. Compact panes place source names and actual scan RTs inside each spectrum, with one shared m/z axis at the bottom. Six stacked spectra are designed to remain readable at MacBook fullscreen sizes; more spectra progressively reduce the available height.

Double-click a chromatogram to open its nearest MS1 scan and enter Walk mode. A double-click on another file adds that file to the comparison. A file appears only once, even if you double-click several of its TIC/BPC/EIC traces. Subsequent single clicks anywhere inside chromatograms move the existing comparison to the selected scan’s RT without adding files. This also works when clicking a file that is not currently included.

Walk, Pan and Zoom box are exclusive mouse modes. In Walk, left-drag across a chromatogram to scrub scans, or use Left/Right to step through the active trace’s MS1 scans. A drag keeps the source chosen at its start, including where overlaid chromatograms cross. Pan and Zoom box restore their usual drag gestures; single clicks still move the existing spectra. Double-clicking returns to Walk. MS2 scans never participate. A polarity-filtered BPC or EIC walks only its own scan rows.

The small eye beside each file includes or removes that file in MS1 Spectra. These eyes are independent of chromatogram checkboxes. Adding a file uses the current inspection RT; before inspection has started, it starts at that file’s first scan with a valid RT. Hiding every spectrum keeps the inspection position, and single clicks do not re-add hidden files. Removing a chromatogram does not remove its file’s spectrum; closing the file does.

All included files follow one reference RT and the selected scan’s polarity. Each file contributes its nearest native MS1 scan of that polarity, with its actual RT shown inside its pane. Positive/negative scans are marked +/−; ? means unspecified polarity and matches unspecified scans only. The reference scan is preserved exactly, including repeated RTs. There is no interpolation, RT alignment or scan averaging. A file outside its acquisition range keeps an empty pane labeled Outside run range. Missing polarity, empty arrays or a read failure also leave a labeled empty pane without stale peaks. A read failure in one file does not prevent other files from updating.

Stacked is the default. Each pane fits its own measured-counts Y scale to the visible m/z window. Match Y gives stacked spectra the same scale. Overlay is independent of chromatogram Overlay and uses source colors. With Match Y off, each MS1 or DAD spectrum’s visible positive peak becomes 100%, recalculated on zoom, pan and scan changes. Match Y on restores shared absolute counts or mAU. Signed, negative-only, zero and empty spectra use the same display rules as chromatograms. The controls do not modify measured intensities. Ordinary profile lines and centroid sticks retain their native rendering. Qualified Sparse Profile gaps are drawn along zero counts. Hover readouts report m/z and measured counts.

m/z zoom and pan are linked across every spectrum and retained while walking, adding/hiding files and switching layouts. Full m/z restores the combined range. Peak labels are selected within the visible window and recomputed with zoom and resizing. Labels fit beneath the file-name band and anchor inward at m/z edges; overlay labels share one collision budget and use source colors. Detailed filenames and scan metadata remain available in tooltips. Spectrum frames update together through a background reader with a bounded latest-position queue, so rapid scrubbing skips obsolete intermediate requests and settles on the final position. Opening each reader for the first time can take longer than subsequent navigation.

Open MS/MS in Kmz2Viewer

The top Open Kmz2Viewer for MS/MS dropdown (also in File) starts a new independent Kmz2Viewer session. Choose Open files from current session… to check one or more loaded source files; files belonging to selected navigator rows start checked, or all files when no rows are selected. Full paths distinguish files with identical names. Chromatogram and spectrum visibility do not limit this list. Choose Open blank session to start without files. Both choices start with no filters and leave existing viewer sessions unchanged.

Right-click a visible m/z peak label in a stacked or overlaid MS1 spectrum, then choose Open MS/MS in Kmz2Viewer. The new session opens only that label’s source file and initializes Precursor m/z to its native, unrounded mass with a ±20 ppm window. Retention time, fragment m/z and all other filters remain unrestricted, regardless of the current MS1 scan, polarity or navigator selection. If no MS2 precursors match, the scan table is empty; edit or clear the filters to explore the file. The source data are not changed. Keep Kmz2Viewer.app beside KmzViewer.app, including inside a portable suite.

Spectral analysis

Right-click an MS1 m/z label and choose Spectral analysis…. A separate window reads matching acquired MS2 scans from that source within ±20 ppm, excludes opposite known polarity, and preselects the nearest available retention time. Review the scan, precursor, charge and collision energy, or choose another scan. MS1 mass alone cannot run this analysis. The window remains tied to its selected spectrum while you navigate the main viewer.

Search references + motifs performs local matching without sending your research spectrum online. First use downloads six public experimental/community collections from GNPS (GNPS-LIBRARY, MASSBANK, MASSBANKEU, SCIEX, Tuebingen natural products and PRESTWICKPHYTOCHEM), about 220 MB. At qualification the prepared pack occupied 56 MiB and contained 82,798 spectra across both polarities. Optional Include BMDMS natural products adds another experimental collection and about 200 MB of downloads. Public packs are cached with dated integrity receipts; there are no automatic updates or private-query histories.

Related spectra searches the full reference precursor range. Its ranking selector offers Fragments + precursor differences (hybrid entropy), Shared fragments (direct entropy), and Shared precursor differences. These are independent ranks, not combined identification probabilities. The top 50 qualifying structure groups appear for each method; duplicate library spectra are grouped using supplied structure keys, with the strongest qualifying representative shown. Weak best-available neighbors can still appear. Library names and annotation provenance remain visible: community annotations are not all confirmed standards.

Default local settings are fragment tolerance ±0.02 Da, a 1% base-peak noise cutoff and three shared ions. Required fragments and required precursor differences accept comma-separated masses. Every entered condition must occur in a reference spectrum within tolerance; conditions filter the entire prepared local corpus before ranking limits. Double-click a query peak to add its mass to the fragment conditions. These filters apply to local reference matching, not motif suggestions or optional learned neighbors. They implement direct conditions rather than a general MassQL language interpreter.

Select a reference to compare its spectrum, with query above zero and reference below. Teal marks direct shared ions; amber marks pairs related by the precursor m/z difference. The table gives both masses, relationship and error. Coverage refers to summed prepared intensity. Displayed pairs use an independent one-to-one alignment and do not claim to expose the entropy scorer’s internal assignments. Load structure retrieves only the selected public reference structure from GNPS. Open reference opens its public record; missing source metadata remains missing.

Motif evidence locally screens all polarity-compatible records in the bundled 996-record MotifDB compilation. Its overlap rank combines assigned motif-weight coverage and query-intensity coverage. An ion contributes once across fragment and loss channels. Labels such as an indole pattern suggest features to investigate; specific scaffold names describe the source motif and do not establish that scaffold in your sample. This is transparent motif overlap, not MS2LDA topic inference or a calibrated classifier. The displayed native query is filtered consistently with motif matching; motif fragments are below zero and precursor-difference features are listed in the table.

Include DreaMS learned neighbors is optional and online. Only after you enable it and click Search does the selected peak list, precursor m/z and available charge go to the public DreaMS service. The first use separately downloads a 1.54 GB public MassSpecGym embedding index, prepared into approximately 593 MiB of local reference data. No model weights, GPU or PyTorch installation is needed locally. Choose Learned similarity · DreaMS in the ranking selector to inspect its top 50 distinct neighbors, with a separate local fragment comparison. It supports known positive mode and singly charged or unspecified-charge queries. Its submitted copy uses a fixed 1% intensity cutoff; local tolerance/noise settings control the comparison, not the learned model. Service/model compatibility is checked; anonymous GPU quotas and service failures can prevent searching. Local results remain usable when it fails. DreaMS scores describe learned spectral proximity, not identification confidence.

Centroid queries preserve their native positive peaks. Profile queries start from native local maxima, including endpoints and one middle sample per plateau; they remain experimental apex samples, not qualified centroid masses. Entropy matching merges neighboring peaks on a separate search copy, removes the precursor region for singly charged/unspecified-charge input and applies visible noise filtering. Motif matching filters native peaks without merging. These preparations are described with the result. Neither original spectra nor acquisitions change. Unknown polarity is not inferred; multiple charge disables precursor-difference matching. When charge is unspecified, a neutral-loss interpretation of an m/z difference assumes compatible singly charged ions.

Save analysis… explicitly writes a .kmzspectra file containing the query, source scan metadata, settings, reference spectra, motif features, pair evidence, optional learned results and loaded structure images. Open analysis… or File → Open spectral analysis… reopens it locally without the acquisition, reference pack or network. There is no automatic history, and candidates never label the original MS1 spectrum. Save before changing scans/settings, which clears current results. The spectral window can also import the query from an older .kmzgnps file.

Optional online GNPS analysis

Online GNPS… opens the previously available standard/analog workflow using the reviewed query; opening it alone sends nothing. Its visible precursor/fragment tolerances, cosine threshold, minimum matched peaks and analog mass range govern Search GNPS. Standard and analog results have separate tabs. Find in public datasets is an explicit repository-occurrence search. Only the selected peaks, essential precursor metadata and settings are submitted; filenames, paths, scan IDs, retention times and full acquisitions stay local.

GNPS applies its own preprocessing, so its cosine and matched-peak counts need not correspond to the fuller mirror spectra. Inspect source provenance, adduct, polarity and structure availability. A successful empty search differs from service failure. Existing .kmzgnps Save/Open remains available in that window, and File → Open spectral analysis routes those files to the GNPS viewer. Saved results reopen without network access; unloaded public assets can be retrieved explicitly.

All searches run in the background with cancellation. Closing waits for worker cleanup. Cancellation stops local work and waiting, but cannot guarantee deletion of a request already accepted by GNPS or DreaMS. Those providers may retain requests. The default local workflow uploads no research spectrum; public reference downloads and structure requests contain only public identifiers or structures.

Sparse Profile files

KmzConvert can optionally generate smaller .sp.mzML files for inspection. A persistent SP prefix (Sparse Profile) in the file navigator identifies their lossy MS1 representation. Compatible embedded v1, v2 or v3 provenance enables one continuous profile line: detected gaps drop vertically to zero, cross the gap at zero counts and rise at the next retained m/z. The outer retained edges also close to zero; isolated measurements retain their dots with a zero-baseline stem. These display-only connections do not reconstruct omitted measurements or inferred peak widths, and add no points to the mzML file. Renaming the file does not remove recognition; the suffix alone cannot enable it. Ordinary mzML and unsupported or malformed sparse provenance retain ordinary rendering.

Retained measurements are unchanged, but low-level detail is omitted. Weak peak widths may be incomplete or altered and short low-level connections may remain. EIC sums use retained intensities, while TIC metadata preserves the acquisition TIC. Use the authoritative full-profile mzML for full-fidelity analysis.

Export SVG

Export SVG… opens a live preview with checkboxes for all loaded chromatograms, initially matching viewer visibility. Export current chromatogram… opens the same preview for the active trace. The initial retention-time bounds match the current viewer range; edit RT minimum/maximum directly. Save SVG writes the exact bytes rendered in the preview and keeps the window open for further exports. Controls affect only the export.

Drag a name in the Show / chromatogram column to reorder the stack; the table retains full filenames and chromatogram descriptions. The insertion line shows where the row will land, and dragging near an edge scrolls long lists. Option/Alt + Up/Down also moves the selected row. Checkboxes and colors travel with the trace. The first checked row is the top trace; the bottom checked row stays at its original retention times. Each successive trace above it shifts by one more RT offset. A positive 1-minute offset therefore stacks traces up and to the right; zero is the default.

Choose Stacked or Overlay in the preview. Ion-only exports retain the shared Ion Counts axis; wavelength-only exports use Absorbance (mAU). Mixed exports use separate counts and absorbance axes, with absorbance on the right. Stacked traces have equal display-space baseline spacing, calculated separately in each native unit; the controls provide separate manual spacing, Y bounds and tick intervals for mixed units. Overlay removes successive baseline and X offsets. Automatic spacing is 1.1 times the visible signal span (including negative values) after horizontal offsets, including interpolated boundary values. A zero-only/empty view has zero automatic spacing. Turn off automatic spacing to enter a distance in the displayed native units. Automatic Y fits the stack; disabling it starts manual fields at the current bounds. Display offsets are not normalization or alignment and do not change source measurements. Horizontal shifts can move traces outside the displayed RT bounds; the Y coordinates include vertical baseline offsets.

The canvas defaults to 7.2 × 4.8 inches, with 12 pt axis labels, 10 pt tick text and 2 pt chromatogram strokes. Legend font size has its own control. Line weight, shading and fill opacity apply to every trace. Shading starts enabled at the viewer’s approximately 6.7% opacity. In the viewer and SVG export, fill always extends downward to the lower of zero and the trace’s finite minimum; this boundary stays fixed while zooming and follows any stack offset. Negative absorbance remains unchanged. Click a trace’s color cell for an individual export color, initially that chromatogram’s viewer color. Preview changes never alter source colors, emphasis, inclusion or trace order in the main viewer.

Show legend, beside the preview, toggles a single-column legend to the right of the plot. Entries read Filename (TIC) or Filename (EIC value), without .mzML/.sp.mzML extensions or ppm tolerances. Range/merged EIC descriptions retain their source meaning. Full legend names are shown without truncation. Legend font size starts at 10 pt, or the largest smaller size that fits all names and entries in the available space. It follows canvas and selection changes until you edit the size; your chosen value then stays fixed. Axis and tick fonts are independent. If your chosen size cannot fit, increase canvas dimensions, reduce legend font size or hide the legend. Very long names or many traces may need a larger canvas for readable text. No labels are drawn over chromatograms.

Only major ticks are drawn. RT ticks default to 1-minute intervals anchored at zero; change the interval only. Y tick labels always use scientific notation (for example 1.5e+04). The Y interval starts with sparse spacing appropriate to the range and follows it until you edit the interval, after which your value stays fixed. Counts fields accept scientific input such as 1e5. Optional faint gridlines are off initially, spaced every 1 minute when enabled, with a separate spacing control. They align to zero at the bottom baseline and follow the stack angle, moving by the RT offset over each vertical spacing step. Angled grids require positive vertical spacing.

The background is always transparent; the preview uses a white surface and preserves canvas proportions. Output defaults beside the most recently loaded mzML, using its basename and an .svg extension. SVG contains editable text and flat vector objects, with no groups, masks, clipping paths or raster images. Numeric cropping interpolates intersections at the RT/Y boundaries. A continuous chromatogram with shading normally uses one filled/stroked path: one continuous stroke dash covers the measured curve, and a gap hides its artificial return to the baseline. Editing path geometry in a vector editor may require adjusting that dash length. When manual Y limits cut a curve, separate fill and stroke objects preserve the cropped geometry; nonfinite gaps remain separate runs. External editors may substitute fonts. A representative plot and its combined path were verified in Illustrator 2026; Vectorcraft import behavior remains untested.

Background work and limits

Loading/extraction show progress and can be cancelled. Document requests queue and deduplicate. Cancel clears pending requests; failed/cancelled files can be retried. Close/Quit waits safely for an in-progress decode and reader cleanup while keeping the event loop responsive. The status bar reports cache reuse.

MS1 inspection performs no integration, alignment, smoothing or centroiding. The optional spectral-analysis window prepares separate MS2 search copies and returns exploratory reference and motif evidence as described above. Help provides this manual and dependency notices. Launch directly from dist/KmzViewer.app or in development with .venv/bin/python -m kmzviewer [run.mzML].

Input compatibility

Version 0.3.0 uses the current KmzSuite conversion metadata. Both viewers reject obsolete suite outputs with: Legacy input received. Please reconvert using the current KmzConvert. Reconvert the original acquisition; renaming the mzML file or editing its header is not a migration. Ordinary third-party mzML remains supported.
