KmzSuite

Suite launcher · version 0.12.0 · updated 2026-10-07

Launch a tool

Press Cmd+Space, type KmzSuite and press Return. Click Open beside KmzViewer, Kmz2Viewer, KmzConvert or KmzCoMet. Each tool runs independently. The five apps live together in a KmzSuite folder: /Applications/KmzSuite/ for the download, or ~/Applications/KmzSuite/ when built from source. They need no Terminal, checkout, virtual environment or rebuilding.

Keep the five apps together in that folder; each may also be opened through Spotlight by its own name. A missing or incomplete executable is shown as Unavailable. Use the refresh button after installing siblings. Launch failures appear in an alert.

The suite uses light panels, dark text, restrained borders and a green accent. Native buttons retain visible enabled, disabled and focus states.

Developer installation and storage

From the checkout, run ./scripts/build.sh, ./scripts/test.sh and ./scripts/install-local.sh. The installer validates a staged replacement before publishing it to ~/Applications/KmzSuite/. Quit installed apps before updating. Failed builds or validation preserve the current working apps. Development builds, environments and tool caches can be removed after independent installation checks; original acquisitions and marked golden references remain protected. One previous working installation is retained for rollback. The launcher has no MS processing or tool settings.
